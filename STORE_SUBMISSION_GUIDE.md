# Guia de submissão para lojas

## Firefox
- Empacote a extensão em um arquivo ZIP contendo manifest.json e a pasta extension/.
- Gere um resumo curto explicando que a extensão registra eventos de uso para Process Mining e não coleta credenciais.
- Inclua links para a política de privacidade.

## Chrome Web Store
- Prepare uma descrição detalhada e imagens de tela.
- Declare que a coleta é opcional e limitada a campos não sensíveis.
- Certifique-se de cumprir as políticas de extensões do Chrome.

## Edge Add-ons
- Submeta o pacote via Partner Center.
- Destaque que a extensão é para análise de uso e não captura dados sensíveis.
- Forneça documentação de privacidade e termos de uso.
